ECIES · the umbrella construction

Key agreement feeding a symmetric cipher

Maps to Fig 1–2 of the teardown: a P-256 key can sign and agree but not encrypt, so ECIES manufactures a one-time symmetric key out of key agreement.

  • Elliptic Curve Integrated Encryption Scheme (ECIES)start here
    Bill Buchanan OBE · 2018
    A dedicated ECIES explainer from the author of asecuritysite.com. Same KEM → KDF → AES shape the teardown draws, without the Apple-specific parameter choices.
  • Elliptic Curve Cryptography: Key Exchange (ECDH), Digital Sig (ECDSA/EdDSA) and Encryption (ECIES)
    Bill Buchanan OBE · ≈ 48 min
    Places ECIES next to ECDH and ECDSA — exactly the "sign, agree, but no encrypt verb" framing the teardown opens with. The long-form version if the short one leaves gaps.
  • Elliptic Curve Integrated Encryption Scheme (ECIES) in Python From Scratchhands-on
    Sefik Ilkin Serengil · 2023
    Builds the ephemeral key, the ECDH step and the symmetric step by hand. The natural companion to the teardown's "rebuilt by hand, from the outside" section.
  • V8d: Elliptic Curve Diffie-Hellman (ECDH) (Applied Cryptography 101)
    Cryptography 101 · Alfred Menezes
    The key-agreement half on its own, from a co-author of the Handbook of Applied Cryptography. Watch first if de·Qs = ds·Qe still feels like magic.
Cofactor · which flavour of ECDH

A two-line parameter that needs the whole group first

No standalone "cofactor" explainer exists on YouTube. The idea only lands once you have group order, generator and subgroup — so build it from two pieces: the definitions, then the attack it prevents.

  • Lecture 17: Elliptic Curve Cryptography (ECC)start here
    Christof Paar · Ruhr University Bochum
    Defines the curve group, its order, the generator and the cyclic subgroup — the vocabulary in which h = #E / n is stated. High-school maths only. Lecture 16 is the prerequisite.
  • V8c: Elliptic curve cryptography (Applied Cryptography 101)
    Cryptography 101 · Alfred Menezes
    Same ground, more compact. Introduces the domain-parameter set (p, a, b, G, n, h) in which h is the cofactor.
  • Diffie-Hellman (DH) Subgroup Confinement Attackdemo
    "DG" · 2020
    The attack that cofactor multiplication prevents, shown on classic DH where it is easier to see. Small channel — take it as a demonstration, not a reference.

Written fallback that beats any video on this point. NCC Group, An Illustrated Guide to Elliptic Curve Cryptography Validation. And the teardown's own conclusion stands: on P-256, h = 1, so the word in the constant name does no work.

X963 · the key-derivation function

Watch HKDF, then delete two things

Also no dedicated video — X9.63 is too small to earn one. It is SHA-256(Z ‖ counter ‖ sharedInfo), the simplest respectable KDF. Every modern explainer teaches HKDF, which is the same idea with an extra "extract" step and a salt. Watch HKDF and mentally remove those two.

  • RFC 5869: HKDF (HMAC-based Key Derivation Function) — A Beginner's Guidestart here
    Network Technician
    Why a shared secret is not yet a key and needs a KDF; the counter-and-info expand loop is the part X9.63 shares.
  • HKDF Deep Dive: Understanding the Mathematics and Implementation of HMAC-Based Key Derivationdeeper
    Network Technician
    Same author, more maths. Fig 3 in the teardown is the X9.63 special case of what this shows.

Skip for this purpose: KDF Explained: Turn Weak Passwords into Strong Keys (Fearless in Rust). It is about password KDFs — Argon2, the other path in this project — not secret-to-key derivation.

GCM · the authenticated mode

CTR mode plus a polynomial tag

Background for the teardown's central claim: the all-zero IV is safe only because the derived key is never reused, and GCM with a repeated (key, IV) pair loses both confidentiality and authentication.

  • What is GCM? Galois Counter Mode (of operation) (usually seen as AES-GCM)start here
    David Wong · author of Real-World Cryptography
    Shorter and more visual. Good first watch.
  • V5b: Authenticated encryption: AES-GCM Galois Counter Mode (Applied Cryptography 101)deeper
    Cryptography 101 · Alfred Menezes
    CTR mode, GHASH, the tag, and the nonce-uniqueness requirement — the theory behind "safe as written, fragile as a design".
